# JS23 課題 No.06 `dolync`

IH12A 17 中尾 元信

## 概要

スローガン：今何やっているを公開できる TODO アプリ<br>

あなたが今まで評価してもらえなかった活動・行動<br>
これらを SNS のライブ感という物と TODO リスト・TODO アプリという、<br>
評価されにくい物を承認欲求で解決するというアプリを構想します。

中尾さん、これまでのやり取りを踏まえて、シンプルかつ「承認欲求」に特化した **dolync** の概要をまとめました。

---

## 📱 dolync（ドゥリンク） アプリケーション概要

### **1. スローガン**

**「『今、何やってる？』を、みんなの承認に変える。」**

### **2. コンセプト**

これまでの TODO アプリは「完了」しないと評価されず、一人で黙々と進める孤独なものでした。
`dolync` は、**「今まさに取り組んでいる状態」**そのものを Public に公開し、Discord のようなリアルタイムなリアクションを通じて、孤独な作業時間を「みんなに評価される時間」へと変える SNS 型 TODO アプリです。

---

### **3. コア機能（MVP 設計）**

- **Public TODO タイムライン**:
- ユーザーが「今、〜〜している」と投稿。完了フラグはあえて持たず、「現在の活動」のライブ感に特化。

- **カスタム・ライブリアクション（Discord 方式）**:
- 投稿に対して、多様な絵文字でリアクションが可能。
- 1 つの投稿に対し、同じ絵文字は 1 回まで（連打不可）。ただし、種類は無限に送れる。

- **ユーザー定義リアクション**:
- ユーザーが自ら「オリジナルの画像」と「タイトル」で新しいリアクションの種類を作成・追加できる。
- 「自分の作ったリアクションが誰かに使われる」という新しい承認体験。

---

### **4. データベース構成（最小構成）**

| テーブル           | 役割                                             |
| ------------------ | ------------------------------------------------ |
| **Users**          | ユーザー情報（名前・アイコン・最終更新）         |
| **Posts**          | 「今やっていること」の投稿データ                 |
| **Reaction_Types** | リアクションの定義（画像 URL・名前・作成者）     |
| **Reactions**      | どの投稿に、誰が、どのリアクションをしたかの記録 |
